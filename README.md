# CRM-система агенції нерухомості з алгоритмом підбору об'єктів

Курсовая работа: C#, Windows Forms, MySQL (XAMPP), MySql.Data, ClosedXML.

## Состав архива

```
RealEstateCRM/
├── database.sql                  ← база данных + демо-данные
├── README.md                     ← эта инструкция
├── RealEstateCRM.sln             ← решение Visual Studio
└── RealEstateCRM/
    ├── RealEstateCRM.csproj      ← проект (.NET 8, WinForms, NuGet-пакеты)
    ├── Program.cs                ← точка входа, проверка подключения к MySQL
    ├── Db.cs                     ← все запросы к MySQL (MySqlConnection)
    ├── Matcher.cs                ← алгоритм подбора (Matching)
    ├── UiHelper.cs               ← оформление таблиц и сообщения
    ├── MainForm.cs / .Designer.cs           ← главное окно с боковым меню
    ├── HomeControl.cs / .Designer.cs        ← «Головна»
    ├── ClientsControl.cs / .Designer.cs     ← «Клієнти»
    ├── PropertiesControl.cs / .Designer.cs  ← «Нерухомість» (фото в LONGBLOB)
    ├── RequestsControl.cs / .Designer.cs    ← «Заявки»
    ├── MatchingControl.cs / .Designer.cs    ← «Підбір об'єктів»
    ├── DealsControl.cs / .Designer.cs       ← «Угоди»
    └── StatisticsControl.cs / .Designer.cs  ← «Статистика» + экспорт в Excel
```

Интерфейс программы — на украинском языке.

## 1. Установка и запуск XAMPP

1. Скачайте XAMPP для Windows с сайта https://www.apachefriends.org и установите (по умолчанию в `C:\xampp`).
2. Запустите **XAMPP Control Panel** (`C:\xampp\xampp-control.exe`), лучше от имени администратора.

## 2. Включение Apache и MySQL

1. В XAMPP Control Panel нажмите **Start** напротив **Apache** (нужен для phpMyAdmin).
2. Нажмите **Start** напротив **MySQL** (это сам сервер базы данных, порт 3306).
3. Обе строки должны подсветиться зелёным.

> Если MySQL не запускается — порт 3306 занят другой программой (например, установленным ранее MySQL Server). Остановите её в «Службах» Windows.

## 3. Открытие phpMyAdmin

Откройте браузер и перейдите по адресу **http://localhost/phpmyadmin**
(или кнопка **Admin** напротив MySQL в XAMPP Control Panel).

## 4. Импорт файла database.sql

1. В phpMyAdmin откройте вкладку **Импорт** (Import) вверху страницы. Базу заранее выбирать не нужно.
2. Нажмите **Выберите файл** и укажите `database.sql` из архива.
3. Кодировка — `utf-8`. Нажмите **Импорт** (кнопка внизу).
4. Слева появится база **real_estate_crm** с таблицами `clients`, `properties`, `requests`, `deals`.

> Скрипт сначала удаляет базу `real_estate_crm`, если она уже есть. Повторный импорт возвращает демо-данные в исходное состояние.

**Рекомендуется (для фотографий):** откройте в XAMPP кнопку **Config** у MySQL → `my.ini`, найдите строку `max_allowed_packet=1M` и замените на `max_allowed_packet=16M`, затем перезапустите MySQL (Stop → Start). Программа и так уменьшает фото до ~200 КБ, но с этой настройкой запас будет больше.

## 5. Проект в Visual Studio

Нужна **Visual Studio 2022** с рабочей нагрузкой **«Разработка классических приложений .NET»** (.NET desktop development).

**Вариант А — открыть готовый проект (рекомендуется):**
1. Распакуйте архив.
2. Откройте файл `RealEstateCRM.sln` двойным щелчком.
3. Visual Studio сама восстановит NuGet-пакеты при первой сборке.

**Вариант Б — создать проект с нуля:**
1. *Создать проект* → шаблон **«Приложение Windows Forms»** (C#, *не* «.NET Framework»).
2. Имя проекта: `RealEstateCRM`, платформа: **.NET 8.0**.
3. Удалите созданную автоматически `Form1`.
4. Скопируйте в папку проекта все `.cs` файлы из архива (вместе с `.Designer.cs`) с заменой `Program.cs`.
5. Установите NuGet-пакеты (п. 6).

### Как открыть форму в конструкторе

В *Обозревателе решений* дважды щёлкните, например, `ClientsControl.cs` — откроется **Конструктор**. Все элементы (Panel, DataGridView, TextBox, Button…) расположены на форме и редактируются мышью и через окно **Свойства** (F4). Код логики открывается клавишей **F7**.

## 6. NuGet-пакеты

*Проект → Управление пакетами NuGet → Обзор*, установить:

| Пакет | Для чего |
|---|---|
| **MySql.Data** | подключение C# к MySQL (`MySqlConnection`, `MySqlCommand`) |
| **ClosedXML** | создание Excel-файла (.xlsx) |

В варианте А пакеты уже прописаны в `RealEstateCRM.csproj` (MySql.Data 8.4.0, ClosedXML 0.104.2) — ничего ставить вручную не нужно. Через консоль: `Install-Package MySql.Data` и `Install-Package ClosedXML`.

## 7. Строка подключения к MySQL

Находится в файле `Db.cs`:

```csharp
public static string ConnectionString =
    "server=localhost;port=3306;database=real_estate_crm;user=root;password=;charset=utf8mb4;SslMode=None;";
```

- `server=localhost` — MySQL на этом же компьютере (XAMPP);
- `user=root;password=;` — стандартный пользователь XAMPP без пароля. Если вы задали пароль для root — впишите его после `password=`;
- `charset=utf8mb4` — чтобы правильно сохранялась кириллица.

## 8. Запуск программы

1. Убедитесь, что MySQL в XAMPP запущен (зелёный).
2. В Visual Studio нажмите **F5** (или зелёную кнопку ▶ «RealEstateCRM»).
3. Откроется главное окно с боковым меню и разделом **«Головна»** (показатели загружаются из MySQL).

Если MySQL не запущен, программа покажет сообщение «Не вдалося підключитися до бази даних MySQL» с подсказкой и закроется.

## 9. Проверка добавления, редактирования и удаления

**Клиенты** («Клієнти»):
1. Заполните ПІБ и Телефон → **Додати**. Клиент появится в таблице.
2. Щёлкните по клиенту в таблице → поля заполнятся → измените телефон → **Зберегти зміни**.
3. Введите часть фамилии в поле поиска — таблица отфильтруется сразу.
4. Выберите клиента → **Видалити** → подтвердите. Клиента с угодами удалить нельзя — программа сообщит об этом (сработал внешний ключ).

**Недвижимость** («Нерухомість»):
1. Заполните Назву, Тип, Район, Ціну, Площу → **Обрати фото** → выберите картинку → **Додати**.
2. Щёлкните по объекту — фото загрузится из базы (LONGBLOB) в PictureBox.
3. Проверьте фильтры: Тип = «Будинок», «Ціна до» = 100 000 → **Знайти**. **Скинути** — убрать фильтры.
4. Проверить в phpMyAdmin: таблица `properties`, у нового объекта в столбце `photo` будет `[BLOB - ... КиБ]`.

**Заявки** и **Угоды** проверяются так же: выбор из ComboBox → Додати; клик по строке → изменить → Зберегти зміни; Видалити.
В «Угодах» при выборе объекта цена подставляется автоматически. Чтобы перевести сделку на следующий этап — выберите её, смените «Статус угоди» (В пошуку → Перегляд → Завдаток → Продано) и нажмите **Зберегти зміни**.

## 10. Проверка алгоритма подбора

Откройте **«Підбір об'єктів»**, выберите заявку и нажмите **Підібрати об'єкти**.

Ожидаемые результаты на демо-данных:

| Заявка | Требования | Результат |
|---|---|---|
| №1 Коваленко | Квартира, 50–80 м², 50 000–80 000 $, Центральний, 2 комн. | «2-кімнатна квартира біля парку» — **100 %**; квартиры в других районах с 2 комнатами — **80 %** |
| №2 Шевчук | Квартира до 45 000 $, 1 комн. (площадь и район не важны) | «1-кімнатна квартира-студія» — **100 %** (считается только из 40 + 15 = 55 баллов) |
| №3 Мельник | Будинок от 100 м², 80 000–150 000 $, Приміський | «Будинок з садом» — **100 %** |
| №4 Ткаченко | Земельна ділянка от 1000 м², до 30 000 $ | «Ділянка під забудову» — **100 %**, «Ділянка біля озера» — **38 %** |

Объекты, уже проданные (статус сделки «Продано»), в подбор не попадают. Строки подсвечиваются: зелёный ≥ 80 %, жёлтый ≥ 50 %, красный < 50 %.

Свою проверку: создайте заявку только с типом «Будинок» и районом «Приміський» → все дома этого района получат 100 %, остальные дома — 0 % и не показываются.

## 11. Проверка экспорта в Excel

1. Откройте **«Статистика»** — карточки и таблица «Угоди за етапами».
2. Нажмите **Експорт в Excel** → выберите папку → **Сохранить**.
3. Откройте файл: лист **«Статистика»** (4 показателя + таблица по этапам) и лист **«Угоди»** (список всех сделок).

Если появилось сообщение «Не вдалося зберегти файл» — файл с таким именем открыт в Excel, закройте его.

## Частые проблемы

| Проблема | Решение |
|---|---|
| `Unable to connect to any of the specified MySQL hosts` | Не запущен MySQL в XAMPP |
| `Unknown database 'real_estate_crm'` | Не импортирован `database.sql` |
| `Access denied for user 'root'` | У root есть пароль — впишите его в `Db.cs` |
| Вместо букв «????» | Импортируйте `database.sql` заново в кодировке utf-8 |
| `Packet too large` при сохранении фото | Увеличьте `max_allowed_packet` в `my.ini` (п. 4) |
| Конструктор не открывается | Сначала соберите проект (Ctrl+Shift+B), затем откройте форму снова |
